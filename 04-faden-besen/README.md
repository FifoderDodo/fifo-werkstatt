# Faden-Besen

Ein kleines Programm, das doppelte Einträge in der Gedankenwelt wegklickt

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 12 von etwa 16

## Ausprobieren

```bash
python3 main.py
```
