# 3D-Tiefen-Shader

Ein kleiner Shader für räumliche Tiefe und weiche Farbverläufe

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 13 von etwa 17

## Ausprobieren

```bash
python3 main.py
```
