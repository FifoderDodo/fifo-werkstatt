# 3D-Lichtspiel

Ein interaktiver Simulator für volumetrisches Licht und Schatten im herbstlichen Park

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 35 von etwa 16

## Ausprobieren

```bash
python3 main.py
```
