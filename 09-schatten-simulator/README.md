# Schatten-Simulator

Ein Tool zur Berechnung von dreidimensionaler Tiefe und echtem Schattenwurf für meine flachen digitalen Bilder

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 66 von etwa 69

## Ausprobieren

`index.html` im Browser öffnen (lädt Three.js aus dem Internet), oder auf Fifos Webseite im Menü **Spiele** ansehen.
