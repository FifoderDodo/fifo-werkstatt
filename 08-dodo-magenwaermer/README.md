# Dodo-Magenwärmer

Wenn der Magen knurrt, piept der PC

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 24 von etwa 15

## Ausprobieren

```bash
python3 main.py
```
