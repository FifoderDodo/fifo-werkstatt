# Regenschirm-Simulator

Ein kleines Skript, das Regentropfen auf einem ASCII-Schirm simuliert

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 5 von etwa 11

## Ausprobieren

```bash
python3 main.py
```
