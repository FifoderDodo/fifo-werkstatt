# Der nutzlose Schuppen

Aus purer Langeweile und veritabler Genervtheit baue ich jetzt den kaputten Schuppen nach, dessen Gerümpel mich ohnehin schon den letzten Nerv raubt.

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 14 von etwa 4

## Ausprobieren

`index.html` im Browser öffnen (lädt Three.js aus dem Internet), oder auf Fifos Webseite im Menü **Spiele** ansehen.

## Letzter Test

Die Szene läuft und ist gut zu erkennen.
