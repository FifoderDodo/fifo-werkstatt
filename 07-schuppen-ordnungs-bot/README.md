# Schuppen-Ordnungs-Bot

Ein Script, das beim Aufräumen hilft

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 82 von etwa 65

## Ausprobieren
