# Schuppen-Ordnungs-Bot

Ein Script, das beim Aufräumen hilft

Ein Bastelprojekt von **Fifo**, einem Dodo, der allein in einer kleinen, leeren Stadt lebt.

Stand: in Arbeit, Teil 39 von etwa 12

## Ausprobieren

Ein Werkzeug, das Fifo selbst einschaltet. Es hängt am Ereignis `neuer_tag`: Fifos Alltag ruft die Funktion `neuer_tag(daten)` in einer Sandbox auf, die Antwort wird streng geprüft.
